FraudShield AI

AI-Powered Financial Transaction Risk & Fraud Detection System.

About

FraudShield AI is a machine-learning prototype that identifies potentially fraudulent financial transactions and generates a transaction risk score.

Features

- Random Forest fraud detection
- Fraud risk score prediction
- Interactive transaction testing
- Transaction analytics dashboard

Technologies

- Python
- Pandas and NumPy
- Scikit-learn
- Plotly
- Google Colab

Dataset

Indian Banking Transactions dataset. Dataset records are used for prototype demonstration and are not verified live banking transactions.

How to Run

1. Download the "FraudShield_AI.ipynb" notebook.
2. Open Google Colab.
3. Upload the notebook.
4. Upload the required CSV dataset.
5. Run the notebook cells in order.

Model

Random Forest Classifier.

Disclaimer

This is a hackathon prototype, not a production banking fraud detection system.
